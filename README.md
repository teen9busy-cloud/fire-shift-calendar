# 🚒 2026년 경남소방 대원 3교대 스마트 근무표 달력

경남소방 대원들의 3교대 순환 규칙(`3팀 ➔ 1팀 ➔ 2팀`)에 따라 2026년 1년치 전체 근무 일정을 직관적이고 큼직하게 보여주는 반응형 웹 달력입니다.  
상담사, 대표, 실무자분들이 PC와 모바일 스마트폰에서 언제 어디서든 빠르고 명확하게 당번을 확인할 수 있도록 제작되었습니다.

## ✨ 주요 기능 및 특징

1. **큼직하고 선명한 대형 달력 (모바일 & PC 반응형)**
   - 작은 스마트폰 화면에서도 한눈에 들어오는 큰 글씨와 전용 컬러 시스템.
   - **1팀**: 코발트 블루 (`#2563EB`)
   - **2팀**: 에메랄드 그린 (`#059669`)
   - **3팀**: 비비드 오렌지 (`#EA580C`)
2. **실시간 오늘 당번 배너**
   - 접속한 날짜를 자동 감지하여 오늘의 근무팀과 내일 근무팀을 상단에 큼직하게 안내.
3. **월간 달력 & 2026 전체 1년 보기 전환**
   - 1월부터 12월까지 월별 상세 달력뿐만 아니라 1년 12개월 전체를 조감할 수 있는 연간 뷰 제공.
4. **팀별 필터링 기능 (1팀만 / 2팀만 / 3팀만)**
   - 상담 일정 조율 및 특정 팀 근무일만 집중해서 보고 싶을 때 원클릭 필터링.
5. **특정 날짜 빠른 검색기**
   - 날짜를 선택하면 해당 일자의 당번 팀과 공휴일 여부를 즉시 계산하여 팝업/안내.
6. **2026년 대한민국 공휴일 완벽 반영**
   - 신정, 설날 연휴, 삼일절(대체휴일 포함), 어린이날, 부처님오신날, 제9회 전국동시지방선거(6월 3일), 현충일, 광복절, 추석 연휴(대체휴일 포함), 개천절, 한글날, 성탄절 등 반영.
7. **개인/상담 업무 메모 기능**
   - 날짜를 터치하여 특정 일자에 상담 메모나 주요 일정을 기록할 수 있습니다 (브라우저 로컬 저장).
8. **인쇄 및 PDF 저장 최적화**
   - `인쇄/PDF` 버튼 클릭 시 웹 브라우저 네비게이션을 제외하고 깔끔한 달력 형태로 출력 가능.

## 🚀 깃허브 페이지(GitHub Pages)로 1분 만에 웹사이트 배포하기

이 프로젝트는 별도의 서버나 빌드 과정 없이 `index.html` 단일 파일로 동작하므로, GitHub 무료 호스팅(GitHub Pages)을 통해 즉시 웹 링크를 생성할 수 있습니다.

### 방법 1. 깃허브 웹사이트에서 바로 올리기
1. [GitHub.com](https://github.com)에 로그인 후 우측 상단의 **[New repository]** 클릭
2. Repository name에 `fire-shift-calendar` (또는 원하는 이름) 입력 후 **[Create repository]** 클릭
3. 생성된 화면에서 **[uploading an existing file]** 링크 클릭
4. 이 폴더 안에 있는 `index.html`, `README.md`, `1.png` 파일을 드래그하여 업로드하고 아래의 **[Commit changes]** 클릭
5. 레포지토리 상단 메뉴에서 **[Settings]** ➔ 좌측 사이드바의 **[Pages]** 클릭
6. **Build and deployment** 항목의 Branch를 `None`에서 **`main`** (또는 `master`), 폴더를 **`/(root)`** 로 선택 후 **[Save]** 클릭
7. 1~2분 후 새로고침하면 `https://<내깃허브아이디>.github.io/fire-shift-calendar/` 형태의 전용 접속 링크가 생성됩니다!

### 방법 2. Git CLI 명령어로 올리기
```bash
git init
git add .
git commit -m "feat: 2026 경남소방 3교대 근무표 달력 웹사이트 초기 배포"
git branch -M main
git remote add origin https://github.com/<내깃허브아이디>/<레포지토리이름>.git
git push -u origin main
```
이후 위 5~6번처럼 GitHub Settings ➔ Pages에서 `main` 브랜치를 지정해주시면 배포가 완료됩니다.
